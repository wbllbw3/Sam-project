## How to submit

1. Put the week's files in the matching `class-XX/` folder (diagrams, source, screenshots — whatever the brief asks for).
2. Add a short `README.md` inside that folder: what it does, how to run it, what is still missing.
3. Commit with a message that names the class: `class-03: add landing page`.
4. Keep the table above in sync — it is the first thing a reviewer opens.
